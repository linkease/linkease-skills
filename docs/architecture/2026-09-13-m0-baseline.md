## Repeatable gate

```sh
sh tests/architecture/m0-baseline.sh
```

The gate verifies inventory coverage and format, both existing profile smoke suites, shell syntax for the root installer and packager, and the recorded size/count metrics.

## Safety and ownership

The worktree already contained an in-progress `asusgo` to `asuswrt` rename before this milestone. It is outside M0 and must remain unmodified and uncommitted by the architecture migration until its owner completes or explicitly transfers it.

## Exit decision

M0 completes when the repeatable gate passes without changing existing install, routing, or runtime behavior. Later milestones must preserve the inventory as historical evidence and replace duplicate implementations rather than layering another permanent compatibility implementation over them.
